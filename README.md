# Causal-Inference-under-Interference-with-Learned-Exposure-Mappings

This repository contains the code for the paper: Causal Inference under Interference with Learned Exposure Mappings.

The repository includes the simulation studies, empirical analyzes, and scripts used to generate the figures reported in the paper.

The California PM2.5 data used in the empirical illustration are publicly available. Simulation data is generated within the code.

If you find this repository useful, please cite the accompanying paper.
